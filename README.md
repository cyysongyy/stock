# 📈 台股投資 Dashboard

> 台股即時看盤、持股損益追蹤與買賣訊號分析工具，支援多位使用者資料各自獨立。

---

## 功能

### 庫存管理
- 持股管理：新增 / 編輯 / 刪除持股，自動計算損益與報酬率
- 買入加碼 / 賣出減碼：自動重算加權平均成本，賣出自動記錄**已實現損益**
- 交易紀錄：完整買賣歷史清單（頭像選單 → 📒 交易紀錄）
- 資產走勢圖：每日快照總市值與成本，總覽卡片顯示折線走勢
- 即時報價：TWSE MIS API，市場開盤期間每 30 秒自動更新
- 首頁市場資訊卡（風險預警、美股收盤、今日預測）可收合：點卡片標題列單張收合／展開，或點「🌐 市場資訊」旁的「全部收合」；收合時只留一行摘要，狀態記在本機；「⚡ 買賣急迫性」與「🔔 即時預警」也可各自點標題收合

### 自選觀察
- ⭐ 自選股清單：追蹤未持有的股票，即時報價與漲跌幅
- 一鍵從自選加入持股、或從分析頁加入自選

### 分析與訊號
- 技術指標：RSI、MACD、MA20、KD（9,3,3）、量能偵測
- 買賣訊號評分：5 項指標綜合評分，強烈買入 / 觀望 / 強烈賣出
- 量增價漲 / 量增價跌：成交量超過 20 日均量 2 倍自動觸發
- KD 黃金交叉 / 死亡交叉 / 超買超賣提示
- 個股 K 線圖、RSI、MACD、成交量圖表
- 美股收盤 → 台股開盤預測（四大指數加權）
- 🧭 首頁「今日台股預測」：依美股、亞股、加權指數收盤算出開盤傾向與區間（與命令列工具同一算法；首頁版不含新聞與 AI 分析）
- ⚡ 即時買賣時機：盤中每 10 秒以即時價重算（把今天的 K 棒換成現價），「立即買入」「立即減碼」跟著報價出現，並跳出提示與語音
- 🎯 依持股狀況的賣出時機：扣掉買賣手續費與證交稅後的報酬與打平價、近月高／近季高壓力分批賣出、跌破月線保護價；單一持股占比過高時提醒減碼
- 🤖 AI 深度分析：支援 Claude / ChatGPT / Gemini / NVIDIA API Key（NVIDIA 金鑰以 `nvapi-` 開頭）

### 提醒
- 價格 / 損益目標警報（瀏覽器推播通知）
- 潛力股掃描、近期 IPO / 新 ETF 追蹤

### 資料
- 資料匯出（JSON）/ 匯入 / 圖片 OCR 匯入
- Google Sheet 雙向同步（每位使用者可設定各自的 Sheet）
- 📱 PWA：可安裝到手機主畫面，離線也能開啟（需以 HTTPS 部署，如 GitHub Pages）

### 多使用者
- 👥 點左上角頭像 → **切換使用者**：新增 / 切換 / 刪除使用者
- 每位使用者的持股、自選、交易紀錄、提醒與 Sheet 設定各自獨立（localStorage 命名空間隔離）
- 市場報價快取與 AI Key 為裝置共用，切換不需重新設定
- 網址加上 `#name=名字` 可直接開啟（或建立）該使用者，方便各自建立主畫面捷徑

## 每日台股預測（命令列）

蒐集美股、亞股、台股收盤與相關新聞，輸出當日開盤傾向預測。需要 Node.js 18 以上，無額外套件。

```bash
node cli/predict.mjs          # 印出報告
node cli/predict.mjs --save   # 另存 reports/predict-日期.md 與 .json
npm run predict              # 等同 --save
```

- 規則式預測：美股加權（費半 40%／那指 25%／S&P 20%／道瓊 15%）占 60%，亞股平均占 30%；區間寬度取加權指數近 10 日報酬標準差（至少 ±0.5%）。權重為經驗值，未經回測校準。
- AI 分析（選用）：設定環境變數 `NVIDIA_API_KEY` 即會另外產生文字分析，`NVIDIA_MODEL` 可更換模型（預設 `meta/llama-3.3-70b-instruct`）。
- 資料來源：Yahoo Finance、Google News RSS。執行環境需能連到 `query1.finance.yahoo.com`、`news.google.com`、`integrate.api.nvidia.com`。
- 退出碼：0 成功；2 無法取得美股資料，不產生預測。

## 風險預警系統（華爾街 → 台股）

伺服器端排程（GitHub Actions，`.github/workflows/risk-monitor.yml`）蒐集美股、亞股與總體風險指標，依參數評分後，
把結果發佈到 `data` 分支的 `risk-state.json`。App 首頁的「🛡️ 風險預警」卡讀這份檔案，必要時另用 Telegram 通知。
資料蒐集不在手機上做（瀏覽器靠免費 CORS 代理不可靠），所以預警不依賴手機是否開著 App。

- **蒐集範圍**：四大指數與費半、輝達、台積電 ADR、VIX、10 年期公債殖利率、美元指數、美元兌台幣、原油、美股期貨、日經、韓國、恆生、台灣加權指數
- **資料來源**：Yahoo → Stooq → CNBC 依序備援，日期落後就換下一個
- **評分**：每條規則觸發加分（總分上限 100），分數對應 注意 ≥ 25／警戒 ≥ 50／危險 ≥ 75
- **持股連動**：依 `exposure` 規則（代號或名稱比對）找出可能受影響的持股；App 端在手機本機比對，**持股不會被上傳**
- **通知**：升級到「警戒」以上才發 Telegram；同等級 6 小時內不重發；回到正常發解除通知；資料來源異常另發一則（12 小時冷卻）；台北 00:00–06:30 警戒級靜音發送，危險級照常響
- **對外連結**：每個觸發因子附 Yahoo 行情連結，卡片另有 CNBC、Yahoo 財經、證交所連結

**啟用步驟**
1. 倉庫需為公開（App 以 `raw.githubusercontent.com` 讀取 `data` 分支）
2. Secrets 沿用背景價格提醒的 `TELEGRAM_BOT_TOKEN`、`TELEGRAM_CHAT_ID`；`SHEET_URL`、`SHEET_SECRET` 選填（有的話通知會列出受影響的持股）
3. 排程只會在預設分支（main）執行，所以先合併到 main
4. GitHub → Actions → **Risk Monitor** → Run workflow 手動執行一次，第一次會自動建立 `data` 分支
5. 開啟 App，首頁應出現預警卡；之後每 15 分鐘（台北週一至週五 21:00 到隔天 10:00）自動更新

**調整參數**：編輯 `config/risk-alerts.json`，下次排程就會生效。`rules` 裡每條規則可以改門檻與分數；`notify` 控制通知等級、冷卻與靜音時段；
`exposure` 控制哪些持股對應哪些因子。本機試跑：`node .github/scripts/risk-monitor.mjs --dry-run --print`（不寫檔、不通知）。

**限制**：GitHub 排程最短 5 分鐘且常延遲，加上 `raw` 檔案約 5 分鐘快取，所以這是預警，不是即時報價；規則與門檻是經驗值，尚未回測。

**真實網路驗證結果**（在可連外的雲端環境跑過一次）：17 個代號 Yahoo 全數取得，CNBC 回應格式與解析確認正確；Stooq 對資料中心 IP 回 403（在 GitHub Actions 上是否也被擋尚未確認，被擋時程式會自動略過並改用 Yahoo／CNBC）。
發現並已修正：Yahoo 的 `TWD=X` 日線最後一根會是過期快照，造成「台幣急貶」誤報，現在匯率類改用即時價覆蓋最後一根。
尚未在正式環境驗證：Telegram 實際發送、Sheet 持股比對、冷卻與靜音時段（以上僅用本機模擬服務測過邏輯）。

## 技術棧

- 純 HTML / CSS / JavaScript（無框架、無建置步驟）
- TWSE MIS API（台股即時報價）
- Yahoo Finance API（歷史 K 線，透過 CORS proxy）
- Chart.js 4.4.1（走勢圖）
- Tesseract.js 5（OCR 圖片匯入）
- Google Apps Script（Sheet 同步，需自行部署）
- Google Apps Script 即時報價中繼（選用，選單「⚡ 即時報價加速」內有程式碼與部署步驟；iPhone 直連 TWSE MIS 常失敗時改由它代抓）
- Service Worker + Web App Manifest（PWA 離線快取）

## 執行方式

- **本機**：直接用瀏覽器開啟 `index.html` 即可，無需伺服器
- **部署**：任何靜態網站空間（GitHub Pages 等）。以 HTTPS 部署時自動啟用 PWA，
  在 iPhone Safari 可透過「加入主畫面」安裝成 App
