# 📈 台股投資 Dashboard

> 台股即時看盤、持股損益追蹤與買賣訊號分析工具，支援多位使用者資料各自獨立。

---

## 功能

- 持股管理：新增 / 編輯 / 刪除持股，自動計算損益與報酬率
- 即時報價：TWSE MIS API，市場開盤期間自動更新
- 技術指標：RSI、MACD、MA20、KD（9,3,3）、量能偵測
- 買賣訊號評分：5 項指標綜合評分，強烈買入 / 觀望 / 強烈賣出
- 量增價漲 / 量增價跌：成交量超過 20 日均量 2 倍自動觸發
- KD 黃金交叉 / 死亡交叉 / 超買超賣提示
- 價格 / 損益目標警報（瀏覽器推播通知）
- 個股 K 線圖、RSI、MACD、成交量圖表
- 資料匯出（JSON）/ 匯入 / 圖片 OCR 匯入
- Google Sheet 雙向同步
- 多用戶：點選頭像切換，各用戶持股與警報資料完全獨立

---

## 多用戶說明

首次開啟輸入名字建立第一個使用者。  
之後點選左上角頭像 → **👥 切換使用者** 可新增或切換。  
每位使用者的資料存於各自的 localStorage 命名空間，互不干擾。

---

## 評分機制

| 評分 | 條件 | 燈號 |
|------|------|------|
| 強烈買入 🚀 | 4–5 項指標看多 | 🟢 綠 |
| 買入 | 2–3 項指標看多 | 🟡 黃 |
| 觀望 | 多空均衡 | ⚪ 灰 |
| 賣出 | 2–3 項指標看空 | 🟠 橘 |
| 強烈賣出 | 4–5 項指標看空 | 🔴 紅 |

注意：台灣股市慣例 ▲漲為紅色、▼跌為綠色。

---

## 技術棧

- 純 HTML / CSS / JavaScript（單檔案，無框架）
- TWSE MIS API（台股即時報價）
- Yahoo Finance API（歷史 K 線，透過 CORS proxy）
- Chart.js 4.4.1（走勢圖）
- Tesseract.js 5（OCR 圖片匯入）
- Google Apps Script（Sheet 同步，需自行部署）

---

## 本機執行

直接用瀏覽器開啟 index.html 即可，無需伺服器。
