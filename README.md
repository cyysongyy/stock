# 📈 台股投資 Dashboard

> 台股即時看盤與買賣訊號分析工具，支援自選股管理與多指標評分。

🌐 線上使用：https://cyysongyy.github.io/stock/

---

## 功能

- 自選股清單管理（新增 / 刪除）
- 即時股價，30 秒自動更新
- 技術指標：RSI、MACD、MA20、KD（9,3,3）、量能
- 買賣訊號綜合評分（5 項指標，強烈買入 / 觀望 / 強烈賣出）
- 量增價漲 / 量增價跌偵測（成交量超過 20 日均量 2 倍觸發）
- KD 黃金交叉 / 死亡交叉 / 超買超賣提示
- 🟢 值得買入持股追蹤：當日漲跌 + 當周漲跌一覽
- 基本面資訊顯示

---

## 評分機制

| 評分 | 條件 | 燈號 |
|------|------|------|
| 強烈買入 🚀 | 4–5 項指標看多 | 🟢 綠 |
| 買入 | 2–3 項指標看多 | 🟡 黃 |
| 觀望 | 多空均衡 | ⚪ 灰 |
| 賣出 | 2–3 項指標看空 | 🟠 橘 |
| 強烈賣出 | 4–5 項指標看空 | 🔴 紅 |

---

## 技術棧

- 純 HTML / CSS / JavaScript（單檔案，無框架）
- TWSE MIS API（台股即時報價）
- Yahoo Finance API（歷史 K 線，透過 CORS proxy）
- Chart.js（走勢圖）
